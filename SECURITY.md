# Security Policy

## Supported versions

Security fixes are targeted at the latest state of `main` and the latest public
release artifacts.

## Reporting a vulnerability

Please do not open public GitHub issues for security-sensitive reports.

Preferred path:

1. Open a private GitHub security advisory for this repository.
2. If that is not possible, contact the maintainers privately through GitHub.

Include:

- A clear description of the issue
- The affected version or commit
- Reproduction steps or proof of concept
- Any privacy, data-exposure, or remote-execution impact you observed

## Scope notes

This project is intended to reduce obvious privacy exposure before downstream AI
usage. Reports about incomplete redaction quality are still useful, but they
should be framed as detection gaps or safety failures, not as guarantees the
project promised to eliminate.
